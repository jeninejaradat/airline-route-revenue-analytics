# airline-route-revenue-analytics
# ✈️ Airline Commercial Analytics Dashboard

> An interactive business intelligence dashboard analyzing airline network performance, route profitability, passenger demand, and commercial strategy using a simulated airline operating from Dubai.

---

## Overview

This project demonstrates how commercial and operational data can be transformed into actionable business insights for airline decision-making.

The dashboard provides an executive view of airline performance, helping identify:

- High-performing routes
- Underperforming destinations
- Revenue opportunities
- Capacity planning recommendations
- Passenger demand trends
- Regional performance

The project was built as a portfolio piece to showcase skills in business analytics, SQL, dashboard design, and data visualization.

---

## Objectives

This analysis answers questions such as:

- Which routes generate the highest revenue?
- Which destinations are the most profitable?
- Which routes require commercial review?
- How does passenger demand change throughout the year?
- Which regions contribute the most revenue?
- Where should additional capacity be added?
- Which routes have pricing opportunities?

## Dataset

This project uses a **simulated airline dataset** created for portfolio purposes.

The data includes:

- 14 international routes
- Passenger volumes
- Revenue
- Profit
- Average fares
- Load factor
- Monthly demand
- Regional classifications
- Flight frequencies

No proprietary airline data was used.

---

## Key Insights

Examples of insights generated by the dashboard include:

- London generated the highest revenue across the network.
- Bahrain produced the lowest operating margin despite a high flight frequency.
- Europe delivered the strongest profitability.
- Peak travel periods significantly increased passenger demand.
- Several Gulf routes demonstrated opportunities for pricing optimization.
